## 📖 Sobre o Projeto

Este repositório contém o código-fonte de um **Portfólio Pessoal e Currículo Web Simples**, desenvolvido utilizando apenas **HTML5** e **CSS3**. O objetivo principal da aplicação é aplicar os fundamentos de estruturação semântica, estilização, layout e boas práticas de design web moderno.

---

## 🗂️ Estrutura de Páginas

O site é composto por **5 páginas** independentes e interconectadas:

1. **`index.html` (Início):** Página principal com mensagem de boas-vindas, menu de navegação, breve resumo do conteúdo e destaques do site.
2. **`curriculo.html` (Currículo):** Versão web do *curriculum vitae* contendo formação acadêmica, experiências profissionais e competências.
3. **`blog.html` (Blog):** Página de artigo técnico sobre front-end (explicando conceitos como Flexbox vs CSS Grid), incluindo recursos visuais (imagens e vídeos).
4. **`fotos.html` (Galeria):** Galeria de fotos ilustrando hobbies e passatempos favoritos, focando em técnicas de posicionamento CSS.
5. **`contato.html` (Contato):** Formulário de contato estruturado para preenchimento de dados pessoais e envio de mensagens.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Utilização de tags semânticas adequadas (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, etc.).
* **CSS3:** Estilização personalizada, uso de classes e IDs organizados, seletores modernos e paleta de cores harmoniosa.
